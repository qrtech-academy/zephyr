# Lecture Material

The following material is covered in the lectures:
* [L01](./L01/README.md): Zephyr, west and the build.
* [L02](./L02/README.md): Devicetree.
* [L03](./L03/README.md): Kernel I: threads, time and work queues.
* [L04](./L04/README.md): Kernel II: communication and application architecture.
* [L05](./L05/README.md): Writing a driver.
* [L06](./L06/README.md): Subsystems and debugging.

Every lecture's examples are Zephyr applications in `LNN/examples/`, each with a README saying how
to build and run it and what to look at. From the repository root, `make build` builds all of
them, and `make examples` also runs them and checks their output.
